2. Map embed column (for Contact page map):
   ALTER TABLE menu_items ADD COLUMN IF NOT EXISTS map_embed TEXT;

Migration files:
- villa-spa/migrations/001_add_content_to_menu_items.sql
- villa-spa/migrations/002_add_map_embed_to_menu_items.sql

After running migrations:
1. Restart dev server: rm -rf .next && npm run dev

3. For Contact page: add Google Maps embed code in "Location Map" field
4. Content appears on frontend pages (About, Contact, Neighbourhood, How to Get Here)
